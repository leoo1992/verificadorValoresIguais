# Security Policy

## Reporting vulnerabilities

Please report vulnerabilities privately through GitHub's **Security > Report a vulnerability** feature, when enabled. Otherwise, contact the maintainer using a private channel listed on their GitHub profile. Never publish exploit details, passwords, tokens, private keys, or confidential data in public issues.

## Supported versions

Only the latest code on the default branch is targeted for security fixes. Older versions and forks are not guaranteed to receive updates.

## Report contents

Describe the affected version, impact, reproducible steps using synthetic data, and suggested remediation, if known. The maintainer can then verify and address the issue before coordinating disclosure.

## Maintenance

Keep dependencies up to date, restrict permissions on GitHub Actions, do not commit secrets, and validate lint, tests, builds, and security scanning where configured.

This policy is documentation only and is not proof that any repository is free from vulnerabilities or meets a quality score.
